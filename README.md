# 🚀 ShadowVoice Live — Stealth Automation for Shadowrocket

Адаптивный самообновляемый конфиг для Shadowrocket с интеллектуальной маршрутизацией. Система автоматически решает, какой трафик направить через VPN (**PROXY**), а какой оставить напрямую (**DIRECT**), обеспечивая максимальную скорость и невидимость для банковских систем.

## 🔄 Как это работает
1. **GitHub Actions** запускается автоматически каждый час.
2. Скрипт `generator.py` собирает актуальные списки доменов из топовых репозиториев:
   - **Российский сегмент:** Банки, Госуслуги, VK, Яндекс.
   - **Зарубежный сегмент:** Google, YouTube, Instagram, TikTok, OpenAI (ChatGPT) и др.
   - **Рекламные домены:** Огромная база для блокировки баннеров и трекеров.
3. **Smart Ping:** Скрипт проверяет доступность узлов через DNS и HTTPS.
4. **Auto-Build:** Генерируется финальный файл `ShadowVoice_Live.conf`, который сразу готов к работе.

## 📲 Установка в Shadowrocket

1. Скопируйте ссылку на **Raw**-версию конфига:
   `https://raw.githubusercontent.com/PAE16/shadow-stealth/main/ShadowVoice_Live.conf`
2. Откройте **Shadowrocket** → вкладка **Config**.
3. Нажмите **+** (плюс) в правом верхнем углу → **Add from URL**.
4. Вставьте ссылку и нажмите **OK**.
5. Выберите добавленный конфиг и нажмите **Use Config**.
6. На главной вкладке установите **Global Routing** → **Config**.

## 🔄 Обновление
Конфиг на сервере обновляется каждый час. Чтобы Shadowrocket подтянул свежие правила:
- Во вкладке **Config** зажмите палец на `ShadowVoice_Live` и выберите **Update**.
- Или включите **On Demand** в настройках конфига для автоматического обновления.

## 🛠 Что внутри конфига
* **DIRECT:** Все российские сервисы (Т-Банк, Сбер, Госуслуги, Ozon, Wildberries) работают без VPN.
* **PROXY:** Полный доступ к YouTube, Instagram, TikTok (с фиксом ленты), ChatGPT, Telegram.
* **REJECT:** Встроенный блокировщик рекламы (вырезает баннеры в приложениях).
* **TikTok Fix:** Специальные правила для обхода региональных ограничений и блокировка QUIC (UDP 443).
* **Stealth DNS:** Использование DoH (DNS over HTTPS) от Cloudflare для защиты от перехвата запросов провайдером.

## 📂 Структура проекта
* `generator.py` — "Мозг" системы. Скрипт на Python для обработки правил.
* `template.conf` — Базовый шаблон с настройками General и Stealth-правилами. (Удален)
* `ShadowVoice_Live.conf` — Итоговый файл (результат работы автоматики).
* `.github/workflows/main.yml` — Инструкции для GitHub по ежечасному запуску.
